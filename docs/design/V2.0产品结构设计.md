# V2.0 产品结构设计

本文维护 V2.0 的入口职责及设计入口。四个入口已划分，各入口已落地的设计文档见下方链接。本文及各入口设计属于 V2.0 开发基线，与[产品需求](../product/需求说明书.md)共同使用，不代表现有代码或线上实现。

| 入口 | 职责 |
| --- | --- |
| 我的工作 | 集中查看和执行分配给自己的项目任务与私人任务，按对应执行状态的个人分类整理，维护默认分类与个人顺序；支持可选备注，规则见[项目设计](V2.0项目设计.md#字段与安排)，不设置团队共享检查清单。 |
| 周报与周计划 | 维护团队共用的日期区间，按区间整理工作总结、批量安排任务、协调人员工作量，查看、编辑和复制文字版；保存即生效，不设置发布或定稿流程。 |
| 项目 | 汇总查看有权访问项目在所选日期区间内的任务执行情况及待建任务；进入具体项目维护任务表、里程碑和待建任务，支持批量录入任务，并通过“里程碑总览”跨项目查看阶段目标。 |
| 团队管理 | 维护团队成员、项目基础信息、项目角色、项目成员及可选团队文案；项目的具体工作在“项目”入口中维护。 |

## 入口设计与原型

- [V2.0 组件与交互规范](V2.0组件与交互规范.md)：四个入口共用的容器选择、按钮位置、表单与返回规则；短操作使用弹窗，信息量大的阅读和编排允许留在当前页面。
- [V2.0 项目设计](V2.0项目设计.md)：任务与待建任务权限、里程碑日期列、历史与未规划节点弹窗；[交互原型](prototypes/project-v2.html)使用模拟数据。
- [V2.0 我的工作设计](V2.0我的工作设计.md)：项目与个人任务共用看板、状态分类及默认进入、手动排序、完成区间与可选团队文案。
- [我的工作交互原型](prototypes/my-work-v2.html)：模拟分类维护、默认流转、拖动、一次性重排及任务操作。
- [V2.0 周报与周计划设计](V2.0周报与周计划设计.md)：本轮确认的流程、日期联动、任务编排、排序和文字同步规则。
- [V2.0 团队管理设计](V2.0团队管理设计.md)：成员与项目配置、多人负责人及移出项目成员的前置条件；本轮仅落地文档。
- [周报与周计划交互原型](prototypes/weekly-v2.html)：下载或克隆后用浏览器打开，使用模拟数据。
- [原型源码与维护说明](prototypes/README.md)：源码、导出关系和重新生成方法。

V1 需求、过程记录与旧原型已清理压缩，迁移参考见[历史基线](../archive/v1/README.md)。V2.0 采用单执行人任务、保存生效及已确认的新权限，具体跨入口与迁移要求见[研发需求](../product/研发需求说明书.md)和[迁移准备](../development/V2.0迁移与研发准备.md)。取消范围以产品需求为准，不从旧代码自动补回业务。
