# V2.0 消息通知

确认日期：2026-10-20。本文件维护新增消息的唯一业务规则；开发代码与部署、Windows 实机证据分别见[实施记录](../development/V2.0实施记录.md)。

## 通知事件

仅项目任务产生消息，私人任务不产生。所有接收人排除实际操作者，限定该项目当前已启用成员：

| 事件 | 接收人 |
| --- | --- |
| 任务真实变为已完成，包括研发负责人自己的任务 | 本项目所有研发负责人 |
| 新建正式任务或待建事项转正式任务，安排执行人 | 任务执行人 |
| 本周期临时新增计划外任务 | 本项目所有研发负责人 |

计划外定义统一见[周报与周计划设计](V2.0周报与周计划设计.md#3-项目与人员视角)。待建转换无论待建创建时间都不触发计划外；已有任务改派不在本期通知范围。

网页、Windows、Agent 共用规则。代完成写明操作者与执行人。重复提交不重复通知，回退后再次完成产生新的完成消息。同次操作对同一接收人合并，批量任务合并为一条，保留每条任务及对应原因。延续和补排不重复提醒计划外。

## 消息弹窗

网页与 Windows 右上角提供消息按钮，点击打开弹窗，按发生时间倒序，每页10条。展示消息内容、项目与上海时间，点击任务打开详情。

只保留发生时间距今七天内的消息，过期清理。离线期间仍生成消息，恢复后可查看。不提供已读未读、红点、未读数、全部已读、删除或筛选。

只查询本人消息，每次按当前项目权限裁剪；已移出项目的内容不展示。点击重新验证权限，任务删除或不可访问时明确提示。

## Windows 系统通知

客户端运行或驻留托盘且已登录、联网时接收新消息；彻底退出后不接收。启动、换号、断网恢复或休眠恢复不补弹历史消息。点击单任务通知进入任务，多任务通知进入消息弹窗。

系统禁用通知不影响应用内消息。系统通知与列表使用同一消息数据，系统展示不产生已读状态。上线前历史业务不补生成通知。
