# 个人工作联动实施记录

日期：2026-10-15。本记录对应本地实现与验收，不代表已提交、发布或部署。业务规则以[研发需求](../product/研发需求说明书.md)为准，操作入口见[任务与个人执行使用说明](任务与个人执行使用说明.md)。

## 交付范围

- 我的工作采用个人看板与可收起的团队任务库：按项目、人员、关键词查找当前有权查看的团队工作，在同页查看任务，认领后加入本人工作。重复加入定位已有事项，明确拆分才新增事项。
- 每人初始化未开始、进行中、已完成三个状态分类；同状态可建多个分类。状态流转仅一个目标时自动选择，多个目标时明确选列；拖动卡片以落点为准，同时提供移动菜单。
- 同一分工可关联多个个人事项；最后一项完成才完成本人分工，新增未完成项或恢复事项会恢复本人分工。团队任务整体完成仍由主负责人确认。退出、转交、归档和上层任务结束保持原执行限制。
- 个人进展通过独立的 `linkedProgress` 字段展示于分工详情，沿用来源标识，不复制进分工进展表，不改变周报原始归集。纯项目经理不可通过此字段越权读取个人内容。
- 新建独立工作直接选择两个计划外标签及对应周次，与事项在同一事务保存。详情内容页直接维护；关联事项继承团队标签，私人事项不提供此标签。
- 手机默认收起团队库，分类在看板内横向滚动；新建表单单列展示，移动菜单可替代拖动。
