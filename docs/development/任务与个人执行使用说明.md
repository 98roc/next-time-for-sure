# 任务与个人执行使用说明

适用范围：第3阶段网页与会话接口。周计划与周报见[独立使用说明](周计划与周报使用说明.md)；通知及完整桌面／Agent业务接入由后续阶段提供。

## 入口与工作流程

1. 在“团队与项目”进入项目的“团队工作”（`/work`）。项目经理提交需求，项目研发负责人或团队负责人处理。接收时指定主负责人，生成一个任务；不会自动分配人员。
2. 研发成员可直接新建团队任务。展开任务的“人员分工”，由组长／团队负责人分配，成员也可认领本人工作。负责小组和执行人须匹配。
3. 成员可以直接在分工上开始、记录进展和完成，也可用“带入个人空间”建立关联事项。个人空间支持独立工作（必须选项目）与私人事项（仅本人可见）。
4. 分工完成前显示尚未完成的个人工作，确认后停止关联执行但保留个人状态、时间。主负责人整体结束任务同样需要确认影响范围，不会替成员完成。

## 看板、进展与时间

- 团队看板固定待开始、进行中、已完成三列。拖动和按钮执行同一业务操作；不能将进行中直接拖回待开始。已取消任务通过筛选查看。
- 上移、移至列末及拖到另一卡片前均保存顺序。保存成功后位置改变；冲突时保留原位置，刷新核对后重新操作。
- 个人分类和排序独立于状态。空分类可接收拖动；手机可横向滑动看板，或使用“移动分类与排序”表单。移除分类只将事项放回未分类。
- 进展逐条记录发生日期、归属周（周一）及内容。本人可补记实际时间，主负责人可修正团队整体时间；这些操作不传播到其他对象。
- 检查清单完成不自动完成事项；累计进度100%不自动结束团队任务。个人事项可展开“本人变更历史”查看历次操作及时间变化。
- 管理者只可按负责小组调整关联归属，不可代改个人内容、状态或实际时间。非项目成员的组长仍可管理本组成员跨项目关联，但不因此获得整个项目的任务访问权。

## 鱼骨式里程碑

- “新增里程碑节点”可创建任务并加入规划，或选择已有任务，避免重复建设事项。
- 点击节点修改日期、查看详情；主负责人可编辑标题、说明与完成标准。普通任务详情也提供相同内容编辑入口。
- 拖到已有日期或未规划区后，填写原因并确认。日期为空代表未规划，不等于计划外。
- “移出里程碑”只移除图中节点，保留原任务、分工、个人事项和历史。可再次选择已有任务加入。
- 同日多个事项共用日期分支；手机改为纵向时间轴。子任务日期晚于父任务会提示核对，不自动顺延日期。

## 阻塞、拆分与停止执行

主负责人或当前参与人可维护团队任务阻塞，分工和个人事项阻塞由本人维护。可记录原因、等待对象或同项目其他任务。阻塞不阻止开始、不自动顺延；等待任务完成也不自动解除。已接入站内通知，见[生命周期与协作使用说明](生命周期与协作使用说明.md)。

一层拆分需要为所有有效分工选择去向，并具备原负责小组的安排权限。迁移保留原分工标识、进展、个人关联和时间；父任务此后只汇总，不新增执行安排。子任务全部完成仍由主负责人确认父任务整体结束。

团队任务结束、取消后，成员可整理既有内容和补记，但不能绕过重开继续执行或新增关联工作。重开父任务不会自动重开子任务，也不代替成员本人恢复执行。

## 常见反馈

- “内容已变化／409”：其他操作已改变当前版本或确认范围。刷新、核对差异，重新预览后提交。
- “没有权限／403”：服务端会重新检查当前身份、项目和负责小组。查看权限不等于安排权限。
- “关联工作已停止”：先由有权限的人重开上层任务；不得通过解除关联绕过限制。
- 浅色、深色跟随系统；输入框、按钮、焦点和禁用状态共用样式。窄屏看板在自身区域横向滚动，页面无需横向移动。
