# 周计划多视图与页内维护记录

日期：2026-10-15。范围：网页周计划入口及其共用任务详情。采用单周展示、顶部切换本周／下周，不做双周并排。业务边界见[研发需求4.4](../product/研发需求说明书.md#44-周计划预计投入与调整)，操作见[周计划与周报使用说明](周计划与周报使用说明.md)。

## 实现

- 默认项目视图按任务合并人员行，增加小组、个人视图；分组使用项目、任务、账号、小组标识，不按名称合并。总任务数去重，人员安排及待分配分别统计。
- 在周计划内新建、选择任务，复用任务详情、人员分工和周安排；任务详情默认沿用主页面选中周。权限、版本和幂等校验继续由既有后端服务承担。
- 当周完成、停止记录在任务下折叠保留；只读用户重组最新发布副本，不读取草稿。
- “后一周继续做”回读目标安排后编辑，保留来源周；移动继续使用既有后端原子移周命令。批量新增支持同时安排到后一周，只补缺失安排，明确反馈分周保存失败。
- 分组转换位于 `apps/web/src/weekly-plans/plan-view.ts`，列表、任务选择及周安排编辑独立成组件。移除已无调用的旧 `PlanCard` 和旧卡片网格样式。
- 没有新增后端命令、权限或数据库迁移；未提交、推送或部署。
