# 桌面配置与版本更新记录

日期：2026-10-15。桌面版本：0.2.0。使用方法见[桌面与Agent使用说明](桌面与Agent使用说明.md#windows客户端)。

## 交付范围

- 桌面加载配置的网页，支持本机、局域网和公网HTTP(S)站点；网页服务与安装包更新目录分别配置。
- 本地设置窗口从菜单或托盘进入，配置原子保存并重启；业务网页不挂载设置或安装IPC，设置IPC校验窗口及主框架。
- 各站点独立持久化Cookie和通知去重，默认本机站点兼容原记录。配置损坏或网页连接失败可进入设置修复。
- 默认从公开项目GitHub Releases检查更新，支持自建更新目录；确认下载和确认安装分开，稍后安装及普通退出都不触发自动安装。
- 同版本不更新、不降级；更新失败提示重试，更新操作串行，下载期间不允许保存配置触发重启。
- 名称统一为“下次一定”，窗口、托盘、安装程序和快捷方式图标直接从网页favicon生成。
- 私有服务器、凭据及运行配置不进入Git或公开安装包。公开包默认网页地址为本机，实际服务通过用户电脑上的配置指定。

## 验证证据

- TypeScript编译、桌面定向ESLint检查通过；桌面10项测试通过，覆盖地址校验、持久化、站点隔离、重复操作、稍后安装及失败重试。
- 真实Electron隔离用户目录验证设置加载、业务网页无配置接口、阻止外站跳转、设置IPC校验与持久化、保存后正常退出。见[运行记录](evidence/desktop-update-runtime.json)和[设置窗口](evidence/desktop-settings.png)。测试抑制自动重启以避免遗留进程。
- 实际`NsisUpdater`和Electron网络请求访问本地静态更新目录，下载本次生成的完整安装包并验证SHA-512；拒绝相同版本、降级及错误校验值。见[更新下载记录](evidence/desktop-update-feed.json)。测试仅以隔离的应用适配器提供旧版本号，不执行安装程序。
- Windows x64 NSIS安装包、blockmap与latest.yml构建成功；可执行文件资源中ProductName及FileDescription为“下次一定”，版本为0.2.0.0。
