## 交付范围

- 团队＋周次唯一共享草稿，按当前负责小组裁剪；项目、小组、人员筛选，允许目标、预计新增百分比、预计天数为空。投入使用DECIMAL(6,2)，前端按百分之一天累计，单列未估算项。
- 前周未完成且当前有效分工结转，清空本周目标和估算，重复执行不覆盖人工内容、不复制个人事项。已停止安排保留并可移出草稿。
- 待分配事项可随计划发布；团队负责人维护未落实小组的待分配事项。发布前展示完整范围，确认摘要绑定当前草稿和来源，重复提交返回同一发布版本。
- 正式计划及周报保存完整文字快照；调整另存修订，旧版本不依赖源记录仍可访问。已发布安排跨组调整、已有明确交付日期变化由团队负责人操作。每次保存记录前后变化和操作者。
- 人工里程碑外／逐周计划外标签，权限分别检查；未标记不统计为计划内。独立工作关联后沿用团队标签，原独立标签保留；正常拆分继承标签。鱼骨图节点详情与任务详情共用标签入口。
- 周报按进展归属周收集分工、关联与独立工作，以及发布计划尚未完成事项；私人事项在来源阶段排除。按任务归集并保留人员及来源，重复文字合并展示，取消／转交／退出注明状态。
- 人工改写、同任务合并、排除与原执行记录隔离；重生成只补入未纳入来源，不覆盖人工结果。源变动提示核对，接受变化更新来源映射而保留措辞。归属周调整只改汇报周期，不改实际发生日期。
- 项目经理等当前团队成员可读、复制正式周报；草稿和来源另行授权。服务每次校验当前团队、源对象归属和版本，旧草稿不能赋予历史小组继续管理的权限。
- 网页入口 `/weekly-plans`、`/reports`，支持 `?week=YYYY-MM-DD` 定位周次；共用输入、按钮、错误和禁用样式。报告按项目展示本周工作＋下周安排、版本切换及复制。

## 数据库与实现

模块位于 `apps/api/src/weekly-plans`，契约位于 `packages/contracts/src/weekly-plans.ts`、`reporting.ts`，网页位于 `apps/web/src/weekly-plans`。

| 存储 | 用途 |
| --- | --- |
| weekly_drafts／weekly_arrangements | 共享计划草稿、每人分工安排和行版本 |
| weekly_pending | 草稿待分配事项；拆分后展开为子任务 |
| weekly_publications | 计划／周报不可变发布快照、递增修订号和确认摘要 |
| report_drafts | 人工整理条目、排除记录和完整来源映射 |
| work_tags | 人工维度、周次、取消标记及并发版本 |
| weekly_events | 周业务及标签变更前后快照、操作者与原因 |

统一组织事务锁串行化组织变化与业务提交；版本冲突返回409，越权返回403。仓储集中SQL，JSON读取经契约验证，正文与错误不输出凭据。
