# 账号与团队管理调整记录

日期：2026-10-14。当前使用方式见[账号与组织使用说明](账号与组织使用说明.md)，业务规则见产品需求3.1及4.14。

## 调整结果

- 超管导航仅保留账号管理、团队管理；服务端目录不返回项目和小组。创建账号与创建团队分开，团队管理员从已有账号选择。
- 账号提供搜索、团队及状态筛选、新增、编辑、删除、启用停用和重置密码；团队提供搜索、新增、编辑名称与管理员、删除。
- 团队负责人保留本团队成员账号创建、启停及重置权限，其他团队和超管账号不可操作；成员关联、小组、项目管理使用明确按钮和弹窗。
- 取消通用操作下拉表单和角色权限配置命令。授权采用固定角色规则，历史策略表保留兼容，不再参与授权。本次没有结构迁移。
- 更新和删除执行事务、身份范围及版本校验。已有团队或业务历史的账号不可删除；团队存在其他成员、小组、项目或历史时不可删除；空团队删除保留管理员账号。审计保留。
- 本人改密前后端均拒绝新旧密码相同；未登录及强制改密时不展示返回工作空间链接。

## 账号设置页面调整（2026-10-14）

登录后进入独立账号设置页，顶部展示返回入口和账号信息；桌面采用左侧分类、右侧内容，窄屏改为横向分类和单列内容。退出登录移至单独的会话区域。

修改密码增加显示/隐藏、确认新密码、两次输入一致性校验及取消修改。Token默认呈现列表与空状态，新建使用弹窗；到期时间须晚于当前时间，永久有效仍须显式确认；撤销增加确认弹窗。完整令牌只在生成后展示，切换分类即卸载并清除明文。

本轮通过前端严格类型检查、构建和Lint，浏览器检查分类切换、密码可见性、新建令牌弹窗及永久有效提示。没有修改当前账号密码、生成或撤销真实令牌；改密提交与Token写入未在本轮重新实测。桌面画面见[账号设置](evidence/ux/account-settings-desktop.png)。
