# V2.0 推荐协作方式

适用范围：已确认的 V2.0 工作流程；现有 V1 服务尚未完成改造。业务权限以[产品需求](需求说明书.md)及各入口设计为准。

1. 团队负责人配置项目、成员和项目角色；每种项目负责人至少一人，可以多人兼任。
2. 项目经理或成员把尚不能明确安排的事项放入待建任务；执行人和日期区间明确后转换为正式任务，多人工作拆成多条。
3. 项目研发负责人提前整理各项目工作，团队负责人在“周报与周计划”按项目或人员协调预计投入。保存即生效，不等待发布。
4. 成员在“我的工作”执行项目任务并整理个人分类；负责人可以代改项目任务状态，系统记录实际操作者。私人任务不进入团队安排。
5. 回顾区间安排和完成情况；未完成且无后续安排的任务自动追加当前周期，核对继承的预计投入并补充本期工作，必要时手动调整排期。
6. 团队负责人维护区间组合的共享文字，其他人生成本人可见范围的汇报。任务变化后核对文字，复制当前显示的版本。
7. 里程碑满足任务完成条件后，由任意本项目研发负责人确认阶段目标；后续任务回退提示核验，由负责人决定是否重开。
